仅需 gist 权限。Classic Token 勾选 gist；Fine-grained 选 Account permissions → Gists: Read and write。创建 Token →

上传时会把业务数据 + Token + Gist ID一并写入你的私有 Gist。业务「导出」JSON 仍不含 Token。

换机链接会带上 Token 与 Gist ID，另一台浏览器打开后自动填入并可自动同步；请勿发给他人。

四层保护说明：
1. localStorage — 日常存储，关闭浏览器不丢
2. IndexedDB — 双重备份，清缓存时自动恢复
3. 文件导出 — 换浏览器/换电脑时用
4. GitHub Gist — 云端备份；开启自动同步后可自动上传/恢复
